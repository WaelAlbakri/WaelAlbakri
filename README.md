## ⭐ Featured Projects

### 🧠 [Sentiment Analysis for Mental Health Statements](https://github.com/WaelAlbakri/Sentiment-Analysis-for-Mental-Health-Statements)
**Excel · Python · SQL · Power BI**

Analyzed 52K+ social media statements with TextBlob to detect sentiment polarity (positive, negative, neutral). Cleaned and structured the data in Excel and Python, stored it in MySQL, and built a Power BI dashboard visualizing emotional trends across mental health statuses such as depression and anxiety.

### 🧬 [Disease Prediction Using Classification](https://github.com/WaelAlbakri/disease-classification-project)
**Python · scikit-learn · XGBoost · Power BI**

Built and compared KNN, Decision Tree, SVM, and XGBoost to predict disease outcomes across a high-dimensional cancer gene-expression dataset and a clinical heart-disease dataset. Applied PCA for dimensionality reduction and evaluated with cross-validation, confusion matrices, and AUC scores (heart AUC 0.996) to handle class imbalance where accuracy misleads. Built a Power BI dashboard to present predictions and insights.

### ⚽ [Predict Soccer Match Winners with Machine Learning](https://github.com/WaelAlbakri/premier-league-match-predictor-ml)
**Python · scikit-learn · pandas**

Built a Random Forest model to predict Premier League match winners, reaching ~67.5% precision. Engineered rolling-average form features (goals, shots, results) and used a time-aware design with only past matches and both-team performance deltas to prevent data leakage, optimizing for precision to prioritize correct calls.

### 📊 [Healthcare Management System (SQL)](https://github.com/WaelAlbakri/Healthcare-Management-System-SQL)
**SQL · MySQL · Lucidchart**

Designed a fully normalized (3NF) relational database simulating healthcare operations, with tables for patients, doctors, appointments, billing, and more. Wrote analytical queries using JOINs, GROUP BY, subqueries, and CASE statements, and modeled relationships with a Lucidchart ERD.

### 📈 [Crime Rate Analysis in Texas](https://github.com/WaelAlbakri/Crime_Rate_Analysis)
**Python · pandas · Matplotlib · Seaborn**

Analyzed Texas crime data from 1979 to 2019: cleaned the dataset, calculated total and per-capita crime rates, and visualized trends. Identified the most and least dangerous years and the most frequent crime types in the state.
